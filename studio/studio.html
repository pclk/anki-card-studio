Checker

The card-quality checks, set once here and used everywhere: Claude runs them while writing cards (validate()), and they drive the Prompt, Analytics, the card's check list in Review, revisions and the checker fixes in Revise, and the verdict in Export. error must be fixed, warn is fixed unless clearly fine, off is ignored; for limits, 0 means no limit. Kept for all your projects. Open What it looks for on any check to see exactly how it decides.

    Notes
    
      
    The package contains two note types, AutoAnki Basic (Front · Back · Extra · Source) and AutoAnki Cloze (Text · Extra · Source), styled like the preview, with night-mode support.
    
      
    Import: double-click the file or File → Import in Anki desktop; AnkiDroid / AnkiMobile can open it too.
    
      
    Each card keeps a stable ID, so re-exporting a revised deck and importing it again updates the existing notes instead of duplicating them (Anki asks how to handle updates on import).
    
      
    Building runs entirely in your browser; it downloads the SQLite engine from cdnjs the first time, so you need to be online.
